## Rules for the report

1. **If zero findings**: Output only the Summary section with zeros and the sentence "No AI-specific defects detected in this diff." followed by Review Notes. Skip Findings and Refactoring Opportunities.
2. **Finding numbering**: Start at 1, increment sequentially. Number matches the finding's position in the severity-ordered list.
3. **Code snippets in findings**: Keep them short (2-8 lines). Show only the problematic part, not the entire function.
4. **Suggestion code snippets**: Show the corrected version when the fix is a direct rewrite. For larger refactoring suggestions, describe the approach and show the function signature.
5. **File paths**: Use paths relative to the repository root.
6. **Line ranges**: Use `L{start}` for single-line issues, `L{start}-L{end}` for multi-line. For issues spanning non-contiguous lines, list them: `L10, L25, L40-L45`.
